| AWS, GCP, OCI | gpuhunt | many | 5.38 to 11.56 | hyperscalers, outside the headline population by design |

Reproduce by normalising the day's rows over the GLOBAL block with the panel switched off
and again with it on:

```python
from dataclasses import replace
from tci import db
from tci.config import load_factors
from tci.normalise import normalise_observations
c = db.connect_readonly()
f = load_factors(for_date="2026-10-04")
rows = c.execute("SELECT o.* FROM observations o JOIN runs r USING(run_id)"
                 " WHERE r.utc_date='2026-09-26' AND r.status='ok'").fetchall()
world = f.countries_of("GLOBAL")
offered = normalise_observations(rows, replace(f, panel=None), 0.877, world)
admitted = normalise_observations(rows, f, 0.877, world)
```

Rows with no country do not survive either call; those were read from `observations`
directly (`WHERE gpu_model='H100_SXM' AND country IS NULL`).

CoreWeave's rows have carried a country since 12 September: North America as US, Europe as
NO. The Europe table covers the UK too and names no site, so NO is a stand-in. Admitted to
EU/EEA through it, CoreWeave would have moved the headline from $3.77 to $3.85 on 25
September. The panel entry is limited to US and GLOBAL instead.

## A rule for Global, not a new source

Civo, Crusoe and Together publish one price with no region. Gate 3 fails them for every
regional block and should. The Global block only needs the hour to be sold somewhere, so
v0.10.0 lets it count a country-less row from a provider named in `factors.yaml:unplaced`.
Hyperstack cannot be named there: it places some of its own rows from the stock feed, and
its unplaced row would count the same hour twice.
