EU‑CRI design system

Component gallery

Every component the index site needs, built against tokens.css and nothing else. Use the Auto / Light / Dark control in the masthead to check both themes — nothing here is designed for one and tolerated in the other. No external requests: system fonts, inline SVG, no images.

1 · Masthead and ticker strip

A broad flat top nav — never a hamburger on desktop; hiding navigation reads as a consumer product. The strip below it carries the whole series family so the first viewport contains data, not a marketing hero.

Live at the top of this page The live dot is the only ambient animation in the system, and the accent teal appears exactly twice above the fold: the dot, and the rule on the print card. Everything else is slate.

2 · The print card

One hero figure per view. Mono, tabular, fixed to two decimals so a live update never reflows the line. Currency is a segmented toggle, not a dropdown — two options should never cost a click to see.

8 · Methodology ledger rows

The page that proves the numbers is a different content type from the page that shows them. Numbered rows, hairline dividers, right‑aligned tabular numerals, marginalia footnote references — it should read like a settlement statement, not a blog post.

EU‑CRI‑M · construction

Hash‑locked. A change to any row requires a new version.

v0.2.0 · sha256:9f4c1d…a1e7
  1. 01

    Source universe1

    Providers operating an EEA‑resident GPU region with a machine‑readable price surface and a published SKU mapping.

    14 sources
  2. 02

    Observation window

    Rolling 24 hours to the 12:00 UTC fix. Observations outside the window are discarded, not carried.

    24 h
  3. 03

    Outlier treatment2

    Winsorise at the 5th and 95th percentile of the tier‑weighted distribution before aggregation.

    ±5%
  4. 04

    Tier weighting

    L1 verified transacted ×1.00 · L2 published with observed fills ×0.60 · L3 list price ×0.15.

    3 tiers
  5. 05

    Hyperscaler cap3

    Combined L3 weight is capped so that list‑price sources cannot set the fix.

    6.5%
  6. 06

    Index formula

    Tier‑weighted arithmetic mean of the winsorised observation set, rounded half‑up to two decimals.

    —
  7. 07

    Publication & lock

    Published daily at 12:05 UTC. The methodology document and the constituent set are hash‑locked; a change to either requires a new version.

    v0.2.0

Notes

  1. 1 The in‑universe source list is versioned alongside the methodology. Additions take effect at the first fix after a 5‑session notice period.
  2. 2 Winsorisation replaces tail observations with the boundary value rather than dropping them, so the observation count in the constituents table is unchanged by the treatment.
  3. 3 The cap binds today: uncapped, the combined L3 weight would be 11.4%. The 4.9pp difference is redistributed pro‑rata across L1 and L2.
